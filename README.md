# Employee Management System

A simple console-based Employee Management System built with C++.

## Features

* Add new employees
* Display all employees
* Delete employees within an age range
* Update an employee's salary by name
* Input validation through a menu system

## Concepts Used

* C++
* Functions
* Arrays
* Strings
* Loops and conditional statements
* Searching
* Data modification
* Menu-driven programming

## How It Works

The program stores employee information including:

* Name
* Age
* Salary
* Gender

Users interact with the system through a console-based menu.
